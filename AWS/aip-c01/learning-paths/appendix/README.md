## Running the mock

Exam 3 has 70 questions, roughly the real exam's 75; you have already taken and graded Exam 1. Work through the mock in this order:

1. Set a timer for 170 minutes.
2. Answer Exam 3 in `../../exams/03/EXAM.md` without looking at the folds.
3. Grade it with the answer key here.
4. For every miss, read the unit section the key points to, then the folded rationale in that unit's knowledge check.
5. Note whether the miss was a knowledge gap or a reading error. The decision tables above fix most reading errors.

Exam 2 is the spare mock if you want a second run.

Every key in the mock table is also the key used in the units, so the two never disagree. Questions marked *medium* confidence are the ones where the question is ambiguous; treat a disagreement there as a discussion, not a failure.
