# Appendix

Reference material for the last review before either exam. Both files are built
from the finished service units, so every term in them is taught somewhere in the
course.

| File | What it is | When to use it |
|---|---|---|
| `glossary.md` | One or two lines on every service and term the course uses, with the unit that teaches it and a link to the AWS documentation page that settles it | Whenever a question names something you half remember |
| `decision-tables.md` | The cross-cutting choices: which storage, which compute, which database, which load balancer, which connectivity, which disaster recovery strategy, which security control, which messaging service. Plus the rules for reading an exam question and the wording that marks a distractor | The final review before the exam |

Neither file is written yet. See `../_build/PROGRESS.md` for status.
